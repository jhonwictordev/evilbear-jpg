# EVILBEAR.JPG

Portfolio autoral de uma identidade criativa multidisciplinar focada em música,
design, ilustração e audiovisual.

## Desenvolvimento

    npm install
    npm run dev

## Validação

    npm run build
    npm test

O projeto usa vinext/React, Tailwind CSS e Framer Motion, com layout responsivo,
SEO básico, navegação por teclado e suporte a redução de movimento.
