# Security policy

## Reporting a vulnerability

Please do not disclose vulnerabilities, credentials, or personal data in a public issue.
Use GitHub's **Security > Report a vulnerability** flow so the report and any supporting evidence remain private.

Include the affected page or component, reproduction steps, expected impact, and a safe proof of concept when available.

## Repository safeguards

- Secrets and local environment files are excluded from version control.
- Dependency auditing and CodeQL run on pushes, pull requests, and a weekly schedule.
- Dependencies and GitHub Actions are monitored by Dependabot.
- GitHub secret scanning and push protection are enabled.
